# SafeSky Digital Agency

A premium, interactive website for SafeSky — a full-service digital agency.

## Features
- Particle network animation background
- Interactive cursor glow effect
- Scroll-triggered animations
- 3D tilt effect on cards
- Auto-rotating testimonial slider
- Animated stat counters
- Responsive design (mobile, tablet, desktop)
- Contact form with submit feedback

## Tech Stack
- HTML5 / CSS3 / Vanilla JavaScript
- Google Fonts (Inter, Space Grotesk)
- CSS Grid & Flexbox
- IntersectionObserver API
- Canvas particle system

## Color Scheme
Blue-dominant dark theme with gradient accents.

## Setup
Simply open `index.html` in a browser or deploy to any static hosting.
